Hi HN,

I built an open-source interactive 3D browser that lets you fly from Earth all the way to the edge of the observable universe (46.5 Gly). All visualizations use real astronomical data.

• Solar system with real orbital mechanics (NASA SSD)
• Milky Way with ESO VVV infrared survey image + procedural spiral arms + 25k bulge stars + Sgr A* black hole
• Local Group: 150 real galaxies (McConnachie 2012) rendered as procedural spiral galaxies
• Laniakea supercluster: 18,856 galaxies from 2MRS with 9 supercluster cores connected by filaments

Tech:
• Three.js (vanilla, no build step)
• Cesium.js for Earth + satellite layers
• Python + PIL for procedural spiral galaxy textures (logarithmic spiral arms, dust lanes, color gradients)

Everything is MIT licensed. Just clone and run `python3 -m http.server 8765`.

The whole thing was built because I wanted to feel the actual scale of the universe — videos and static images don't quite do it. Watching yourself fly from Earth to the cosmic web is a different experience.

Would love feedback. What's broken, what's missing, what would you want to see next?
